# PRAGMATA Grace Mod
Небольшой Lua-мод для REFramework, возвращающий постепенное автоматическое восстановление шкалы взлома Дианы.

Это не бесконечная шкала взлома и не бесконечное время взлома — используется найденная в игровых данных оригинальная механика `HackingGaugeAutoRecovery`.

### Установка

1. Установите REFramework для PRAGMATA.
2. Скачайте последнюю версию мода из Releases.
3. Скопируйте папку `reframework` в папку игры.
4. Итоговый путь:

   `PRAGMATA/reframework/autorun/pragmata_grace.lua`

5. Запустите игру.

### Удаление

Удалите:

`PRAGMATA/reframework/autorun/pragmata_grace.lua`

и перезапустите игру.
